Privacy Policy & Terms of Use for PageScout

Last updated: October 29, 2026

This Privacy Policy & Terms of Use (“Agreement”) governs the use of the Chrome extension “PageScout” (“Extension”) provided by the Developer.

By installing, accessing, or using the Extension, you agree to the terms described in this Agreement.

1. Purpose of the Extension

PageScout is an AI-powered browser extension that connects the current web page to a large language model (LLM) of your choice. It assists users with:

  • analysis of the current webpage content;
  • chatting with an AI assistant in the browser panel;
  • discovery and execution of WebMCP tools published by the page itself;
  • extraction and processing of webpage information through the assistant;
  • execution of approved actions on the page, including generated JavaScript (see Section 5).

The Extension operates by accessing the current browser tab, webpage content, and user-provided inputs necessary to perform requested functionality.

2. Information Processing

Depending on the features you use, PageScout processes:

  • your LLM connection settings: endpoint URL, model name, and API token;
  • conversation messages, model responses, tool calls, and tool results, which may include current-page information;
  • the current page URL and title, sent as context with assistant requests;
  • names, descriptions, and schemas of tools published by the current page;
  • when you request a network-resource summary, limited recent resource timing entries, including sanitized URLs and timing, status, size, and protocol fields. Query strings, fragments, and credentials are removed from URLs. The summary excludes request and response headers or bodies, cookies, and authentication values;
  • local activity information, including tool names, timing or step counts, page document and snapshot identifiers, and error codes or messages. Error messages may contain details supplied by a page or service.

PageScout does not continuously record browser traffic. Network-resource information is returned only when requested through the relevant tool. Page-provided tools may return other information available to those tools.

Assistant requests are sent to the LLM endpoint you configure and may include conversation messages, the current page URL and title, tool descriptions and schemas, tool calls, and tool results, including page content or other information returned by tools. Your API token is sent in the Authorization header. The endpoint must use HTTPS, except for localhost/127.0.0.1 during local development.

3. Data Storage

The endpoint URL, model name, and API token are stored locally in chrome.storage.local until you change or remove them. The API token is stored as an extension setting and is not encrypted by PageScout.

Conversation state, session tool permissions, and the activity log are held in side-panel session memory and are not retained by PageScout after that session ends. Closing the side panel ends the session and clears its session permissions.

You can review or change connection settings in the extension, remove the Extension's stored data through Chrome, or uninstall the Extension. Your LLM provider may retain information you send to it under its own policy; PageScout cannot delete it from the provider's systems for you.

4. Third-Party Services and AI Providers

The Extension works with the LLM provider whose endpoint you configure yourself. By using the Extension, you acknowledge and agree that submitted content may be transmitted to and processed by that provider. Data handling on the provider's side is governed by that provider's own policy.

The Developer does not control and is not responsible for the privacy practices of third-party services, how third parties process transmitted information, or their actions, outages, and security incidents.

The WebMCP tools published by the page and the JavaScript you approve run in the page's context and may contact that page's own services — the same as if you performed those actions on the page manually.

Page content, tool results, conversation messages, and errors may contain personal, confidential, or authentication information. PageScout does not filter all such information before sending it to your configured endpoint. Do not submit information you are not authorized to disclose to that provider.

5. Executing Code and Using Tools on the Page

Tool calls normally require your approval or are handled under their read-only designation. If you choose to remember a tool permission, PageScout remembers that choice only for the current side-panel session. It applies to the same tool name across pages and tool sources, with no individual revoke control. A same-named tool may therefore be approved automatically on another page during that session, including a tool that otherwise requires confirmation. Review tools and arguments before remembering permission; close the side panel to clear session permissions.

The built-in evaluate_script tool runs JavaScript in the current page's context. The code may read or change page-visible content or state and may make requests using the page's own context. Review the displayed code and arguments. A remembered permission for a tool with the same name may apply to evaluate_script without a new confirmation during the session.
