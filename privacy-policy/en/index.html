Privacy Policy & Terms of Use for PageScout

Last updated: October 7, 2026

This Privacy Policy & Terms of Use (“Agreement”) governs the use of the Chrome extension “PageScout” (“Extension”) provided by the Developer.

By installing, accessing, or using the Extension, you agree to the terms described in this Agreement.

1. Purpose of the Extension

PageScout is an AI-powered browser extension that connects the current web page to a large language model (LLM) of your choice. It assists users with:

  • analysis of the current webpage content;
  • chatting with an AI assistant in the browser panel;
  • discovery and execution of WebMCP tools published by the page itself;
  • extraction and processing of webpage information through the assistant;
  • execution of approved actions on the page, including generated JavaScript (see Section 5).

The Extension operates by accessing the current browser tab, webpage content, and user-provided inputs necessary to perform requested functionality.

2. Information Processing

In the course of its operation, the Extension processes the following data:

  • LLM connection settings entered by you: API token, endpoint URL, and model name;
  • chat messages and tool execution results, including current-page content obtained by tools;
  • names, descriptions, and schemas of the WebMCP tools published by the page;
  • technical session events (tool discovery, confirmations, errors) kept in a local activity log of no more than 200 entries, with no chat content, tool arguments, or keys.

This information is transmitted only to the LLM endpoint you configure. On each request to the assistant, the Extension sends to that address the chat messages, tool metadata and results, and your API token in the Authorization header. The endpoint must use HTTPS (the only exception is localhost/127.0.0.1 for local debugging). No data is transmitted to the Developer.

3. Data Storage

The Developer does not store user data: the Extension has no servers or databases of its own.

LLM connection settings are stored locally on your device in chrome.storage.local and are kept until you change them or remove the Extension's data in Chrome. These are the only data the Extension ever writes to disk.

Chat messages and the activity log exist only in the panel's session memory and disappear when the panel closes.

You can review and change the settings at any time, or remove the Extension entirely — along with all its local data.

4. Third-Party Services and AI Providers

The Extension works with the LLM provider whose endpoint you configure yourself. By using the Extension, you acknowledge and agree that submitted content may be transmitted to and processed by that provider. Data handling on the provider's side is governed by that provider's own policy.

The Developer does not control and is not responsible for the privacy practices of third-party services, how third parties process transmitted information, or their actions, outages, and security incidents.

The WebMCP tools published by the page and the JavaScript you approve run in the page's context and may contact that page's own services — the same as if you performed those actions on the page manually.

Avoid submitting confidential, sensitive, or legally protected information unless you fully understand the associated risks.

5. Executing Code on the Page

The built-in evaluate_script tool runs JavaScript in the context of the current page only after your explicit one-time approval: the confirmation card shows the complete function source and its arguments.

The browser debugger is attached for the duration of that single approved call and is detached immediately afterwards, regardless of outcome.

Approval cannot be granted “forever”: it works once and is bound to the exact page, tool set, and arguments.

The Extension:
